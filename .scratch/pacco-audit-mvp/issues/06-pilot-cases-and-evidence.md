# Choose the pilot scenarios and acceptance evidence

Type: grilling
Status: resolved
Blocked by: 05

## Question

What is the smallest parallel pilot that demonstrates the required status and history checks, and what evidence will show that each criterion passed? See §4.7–§4.8 and [Choose the pilot LAN and recovery setup](05-lan-and-recovery-setup.md).

## Answer

- Use one intake staff member and two auditors. Follow one real transaction through suspension, resubmission, explicit audit resumption, and completion. Use a second pending transaction assigned to the other auditor. Have each auditor find the other auditor's transaction through the corresponding project on Projects. Ask the team to find the transactions at each relevant status and use history to explain how they got there.
- Run the pilot on the office LAN in parallel with Excel as the official working record. Record the office resources, participants, and real cases in [Confirm PACCO pilot assignments and cases](07-confirm-pilot-assignments.md).
- Keep one project record listing AC-01 through AC-10, each result, and a reference to its evidence. Use development checks for AC-01 through AC-08, including the checklist and reprint checks. For the official pilot, have the PACCO reviewer validate the configured checklist set and compare the print layout with the supplied specimen from [Confirm the approved PACCO pilot references](04-approved-pacco-references.md).
- Use the system administrator's scheduled-backup and full-restore evidence for AC-09. Use the supervising auditor's observations of the parallel run for AC-10.

The approved references and confirmed office assignments are required for the official pilot. Clearly labeled fixtures support the development checks in the meantime.
